### why/we made this
we made this to process physical documents to digital and then access those text and do ths at scale. while batching is not supported but we can receive good quality with seuqential as long as the GPU is high-end. 

### how it works
simple, you call the class, specify the images and run the code and it will do all receipts, docs and digitalise them. 

#### installation
**install transformers**

`pip install transformers==4.56.1`

**install pyveis**

`pip install pyvips`

**install some libs on linux**

`apt update`

`apt install -y libvips42 libvips-dev`
